**Notes:**
AutoMapper is case in-sensitive, it will map when cases of names are not same 
	when DTO is property but entity are field type and both are public with same name will still match
	but fail if data types are inconvertable or name is different 


1. Add AutoMapper and AutoMapper.DependencyInjection packages

Under Configuration folder:
2. Create a generic AutoMapper class file which is common for all services

3. Inject Profile and create a constructor

4. In the constructor create methods with CreateMap<Src, Dest>();

5. Create 1 for each type even when src, destination only interchanges

6. Add .ForMember(dest => dest.field, opt => opt.MapFrom(src => src.field));
	when source field is not same as destination field

   Add .ForMember(dest => dest.field, opt => opt.Ignore());
	when we want to ignore any field while mapping

7. Add .ForAllMembers(opt => opt.Condition((src,dest,srcMember) => srcMember != null)) 
	when we want to map only non-null fields from source

8. Use .ReverseMap() for automatic reverse mapping of source, destination

9. In program.cs file, add builder.Services.AddAutoMapper(typeof(any one mapper class name));
	This still scans the assembly, takes all the class inheriting Profile and registers all of them

10. We can inject using IMapper _mapper in the service layer
	
11. Do var result = _mapper.Map<DestinationClass>(source element);

12. Do _mapper.Map(source, destination) which automatically updates the in the destination variable with new mapping
